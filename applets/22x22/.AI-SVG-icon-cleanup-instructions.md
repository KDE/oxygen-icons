# AI SVG Icon Cleanup Instructions

For the given SVG icon files:

1. Clean the SVG code without changing the visible artwork.
   - Remove editor-only metadata, Inkscape/Sodipodi namespaces, named views, path effects, unused ids, and repeated inline style noise.
   - Keep only necessary SVG structure, defs/styles, groups, paths, transforms, and paint rules.
   - Factor repeated styles into CSS classes where practical.
   - Preserve all path `d` geometry exactly unless explicitly asked to alter the drawing.

2. Make theme color usage consistent.
   - If any object/path uses `#232629` as fill or stroke, replace that paint value with `currentColor`.
   - Ensure those objects inherit from `.ColorScheme-Text`.
   - Keep `.ColorScheme-Text { color:#232629; }` in the stylesheet.
   - KDE symbolic icon coloring is most reliable when each painted element has `class="ColorScheme-Text"` and direct paint attributes such as `fill="currentColor"` or `stroke="currentColor"`.
   - Do not hide the only `currentColor` paint declaration inside a custom CSS helper class such as `.question-stroke`; KDE may not recolor it correctly.
   - It is OK to keep shared non-paint attributes in a class, but theme paint (`fill`/`stroke`) should remain directly visible on the painted SVG element or on a simple `.ColorScheme-Text` group.
   - Do not replace intentional non-theme colors such as red warning/error overlays.

3. For 24x24 copies made from 22x22 icons:
   - Copy the cleaned 22x22 SVG files into the `24x24` target directory.
   - Set root document size to:
     `width="24"`
     `height="24"`
   - Wrap all visible artwork after `<defs>` in:
     `<g transform="translate(1,1)"> ... </g>`
   - This keeps the original 22x22 artwork unchanged and adds 1px empty space on all sides.

4. Validate after editing.
   - Run:
     `xmllint --noout <files>`
   - Search to confirm there is no direct artwork use of `#232629`, only the stylesheet definition:
     `rg "#232629|stroke:#232629|fill:#232629|currentColor" <files>`
   - Render-check if possible:
     `rsvg-convert -w <size> -h <size> <file> -o /tmp/<name>.png`

5. Be conservative.
   - Do not change names, visual colors, opacity, stroke widths, transforms, or path geometry unless required.
   - Do not overwrite unrelated files.
